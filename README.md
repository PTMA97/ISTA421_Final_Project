\# ISTA 421 Final Project



\## Project



This project predicts earthquake magnitude from Arizona Geological Survey catalog features using supervised regression.



The three models used are:



\- Ordinary Least Squares Regression

\- Ridge Regression

\- Decision Tree Regression





Dataset:

\-earthquake\_data.csv



How to use:

\-Open project Folder

\-Make sure dataset is in same folder

\-Open 'Final\_Project\_PaulAllen.ipynb'

\-Run the notebook top to bottom
